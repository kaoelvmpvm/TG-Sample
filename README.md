# 幸福 GIVE ME 5 健康 4 EVER｜獨立重製版

以原始印刷桌遊卡牌與遊戲規則為依據重新實作，並未引用第三方測試網站的 JavaScript、HTML 或 CSS 程式碼。

## 功能

- 主遊戲：96 張主牌／16 張魔法卡、2–6 人共用裝置、任務認證、五正成套、健康幣與並列名次。
- 幸福心臟病：80 張五正卡、輪流翻牌與喊牌、同桌真人搶拍、教師紀錄收牌與犯規者。
- 共 112 張原版卡牌，整合單一 WebP 圖片圖集；支援點選卡片放大。
- 本機存檔、存檔驗證、復原步驟、手牌交接遮罩、響應式介面與無圖片備援。
- 核心遊戲規則與 DOM 完全分離，可透過 Node.js 進行單元與模擬測試。

## 執行與部署

靜態網站可部署到 GitHub Pages，無後端、無 API 金鑰。於 GitHub 儲存庫 **Settings → Pages → Build and deployment → Deploy from a branch → main / root** 啟用。

本機測試：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000/
```

遊戲測試：

```bash
npm test
```

## 檔案

- `game.js`：原創狀態機、魔法卡、成套、計分與心臟病判定
- `app.js`：原創畫面、事件處理、存檔和錯誤回饋
- `cards.js`：依正式印刷 PDF 分類並逐張編碼的卡牌索引
- `assets/cards-atlas.webp`：從使用者提供的原始卡面排版擷取，合併成的圖集（8 欄 × 14 列）
- `tests/game.test.mjs`：卡牌完整性、存檔、回合與 200 場自動化對局測試

## 目前版本與待驗證事項

目前版本是 **2–6 人共用一台裝置**，不提供網路多人連線。完整文字以原版卡面圖片為準；遇到玩家未完成任務時，為避免無限制操作，未完成卡牌暫時回到主牌堆底部。這項處置、魔法卡的邊界情況、心臟病的單機裁判輸入方式，仍應與原創者確認後列入正式版規則。

原版遊戲規則要求 4–6 人；為教學測試方便，本程式放寬至 2–6 人。成套時採取可解釋的自動推薦，後續可增加玩家自主選牌。公開投影下，單一裝置不可能完全保障私人手牌；需使用不投影的裝置操作或改為多人手機模式。

卡牌圖檔與其設計權利由原桌遊權利人持有。對外使用、修改與再發布應依權利人的使用條件進行。
## V1.2 主遊戲專注式介面

- 主畫面以當前玩家、當前操作階段、原版卡面、手牌與五正摘要為主。
- 點選手牌先預覽，再確認出牌；仍可拖曳至出牌區直接出牌。
- 集牌區依玩家及面向查閱，完整操作紀錄、返回首頁與復原移入選單。
- 保留原有規則引擎與幸福心臟病介面。


## V1.3｜沉浸式桌面

- 主遊戲新增木質桌緣、綠色桌布與簡潔的中央操作區。
- 增加玩家座位與健康幣、成套數提示，清楚標示目前玩家。
- 主牌堆、魔法牌堆改用立體牌堆呈現，並顯示剩餘數量。
- 扇形手牌支援點選預覽、確認出牌及桌面／手機拖曳出牌。
- 出牌和補牌提供不阻塞遊戲邏輯的短動畫，遵循降低動態效果的系統偏好。
- 保留 V1.2 的專注式資訊分層、公開集牌區抽屜與主遊戲規則；幸福心臟病未修改。
