# 幸福 GIVE ME 5 健康 4 EVER｜獨立重製版

以原始印刷桌遊卡牌與遊戲規則為依據重新實作，並未引用第三方測試網站的 JavaScript、HTML 或 CSS 程式碼。

## 功能

- 主遊戲：96 張主牌／16 張魔法卡、2–6 人共用裝置、任務認證、五正成套、健康幣與並列名次。
- 幸福心臟病：80 張五正卡、輪流翻牌與喊牌、同桌真人搶拍、教師紀錄收牌與犯規者。
- 共 112 張原版卡牌，整合單一 WebP 圖片圖集；支援點選卡片放大。
- 本機存檔、存檔驗證、復原步驟、手牌交接遮罩、響應式介面與無圖片備援。
- 核心遊戲規則與 DOM 完全分離，可透過 Node.js 進行單元與模擬測試。

## 執行與部署

靜態網站可部署到 GitHub Pages，無後端、無 API 金鑰。於 GitHub 儲存庫 **Settings → Pages → Build and deployment → Deploy from a branch → main / root** 啟用。

本機測試：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000/
```

遊戲測試：

```bash
npm test
```

## 檔案

- `game.js`：原創狀態機、魔法卡、成套、計分與心臟病判定
- `app.js`：原創畫面、事件處理、存檔和錯誤回饋
- `cards.js`：依正式印刷 PDF 分類並逐張編碼的卡牌索引
- `assets/cards-atlas.webp`：從使用者提供的原始卡面排版擷取，合併成的圖集（8 欄 × 14 列）
- `tests/game.test.mjs`：卡牌完整性、存檔、回合與 200 場自動化對局測試

## 目前版本與待驗證事項

目前版本是 **2–6 人共用一台裝置**，不提供網路多人連線。完整文字以原版卡面圖片為準；遇到玩家未完成任務時，為避免無限制操作，未完成卡牌暫時回到主牌堆底部。這項處置、魔法卡的邊界情況、心臟病的單機裁判輸入方式，仍應與原創者確認後列入正式版規則。

原版遊戲規則要求 4–6 人；為教學測試方便，本程式放寬至 2–6 人。成套時採取可解釋的自動推薦，後續可增加玩家自主選牌。公開投影下，單一裝置不可能完全保障私人手牌；需使用不投影的裝置操作或改為多人手機模式。

卡牌圖檔與其設計權利由原桌遊權利人持有。對外使用、修改與再發布應依權利人的使用條件進行。

## V1.2 主遊戲專注式介面

- 主畫面僅保留當前玩家、單一操作階段、私人手牌與五正蒐集摘要；其餘資訊放入抽屜式選單。
- 點選手牌先預覽，再確認出牌；可繼續將手牌拖曳到出牌區直接出牌。
- 公開集牌區可依玩家及五正面向查閱；完整操作紀錄與復原隱藏於選單。
- 幸福心臟病及原本的規則引擎保持不變。

## V1.4｜手牌與集牌操作修正

- 統一滑鼠、觸控筆與手機觸控拖曳處理，取消互相衝突的瀏覽器原生拖曳。
- 拖曳距離達 45px 後，無須放至中央指定區域即可放開出牌；輕點仍先預覽、確認後出牌。
- 強化指標捕捉與取消復原，避免滑鼠拖出元素後卡住。
- 公開集牌區常駐於五正蒐集進度上方，顯示較大的原版卡面，支援橫向瀏覽及全部玩家展開。
- 遊戲核心 game.js 不變；沿用原始計分及成套規則。

## V1.5｜互動回饋
- 主遊戲在完成任務時顯示蒐集結果，卡面進入集牌區並短暫高亮。
- 成套認證與獲得魔法健康幣時，顯示明確得幣量，金幣短暫飛向對應玩家座位。
- 魔法卡效果提供對應名稱與實際執行結果；影響的玩家座位高亮。
- 音效由 Web Audio API 即時合成，不使用第三方錄音；**預設關閉**，於遊戲選單開啟。
- 動態效果可於選單關閉，也遵守系統減少動畫偏好。效果只改變呈現，不改動 `game.js` 狀態機。


## V1.6｜幸福心臟病平板環繞版

- 幸福心臟病改為四側拍牌：上、下、左、右各一個「拍」鍵，模擬四位學生圍著平板進行。
- 中央新增大型「翻」鍵；翻牌者可直接按下，不必再到外部操作列。
- 移除心臟病模式中不必要的最近紀錄與蒐集板，只保留喊牌、桌面累積、輪到翻牌者與教師處理按鈕。
- 新增「應拍未拍」檢測：若上一張牌實際應拍，但無人拍牌，按下「翻」會把桌面卡牌平均分回所有玩家。
- 若已有人拍牌，系統會先要求教師登記最後拍到／拍錯／喊錯者，完成後才能繼續翻牌。
- 遊戲規則引擎新增 `iceMissedSlap()`，並補上對應單元測試。

## V1.7｜心臟病固定座位自動裁判（數位版規則）

- 四人座位上→右→下→左，第一張手動翻，其後自動輪替。
- 非匹配牌 2.8 秒後自動翻下一張；匹配牌開放 3–6 秒限時拍牌（預設四秒）並閃紅框。
- 系統記錄拍牌次序、重複觸控只算一次。四人都拍，最後拍者收牌；有人未拍，未拍者平分桌牌；不該拍而拍錯者收牌。
- 提供倒數、結果提示、暫停，以及瀏覽器背景自動暫停。
- 極近時間的同時觸控結果受平板硬體與瀏覽器事件順序限制。
- 此為數位版擴充規則，不取代原桌遊規則。


## V1.8

- Each seat displays cumulative received penalty cards, independent of its current hand. These counters are saved and reset for a new game.
- Identical countdown durations whether the card matches or not; red frame pulses in the final three seconds and accelerates at two and one seconds.
- The live UI no longer reveals whether the current card should be slapped.


## V1.9｜平板四人環繞介面修正
上、右、下、左玩家的拍牌按鈕與受罰張數改為獨立框；倒數最後 3 秒不論牌面是否相符，皆以獨立紅框逐漸加速提醒，暫停時不閃。正誤由遊戲引擎依原版卡牌面向與喊牌比對，僅在判定後顯示結果。實際平板 UI 尚待設備驗收。


## V1.9.2｜四向翻牌與加速紅框

- 將原本位於卡牌旁的單一「翻」鍵移除，改在上、右、下、左四個玩家位置各設置獨立「翻」鍵；只允許固定順序中輪到的玩家啟動第一張牌，後續按既定規則自動翻牌。
- 各座位仍有獨立「拍」鍵與累計受罰牌數，互相不遮擋。
- 倒數最後 3 秒紅框亮暗交替閃爍，剩餘 2 秒及 1 秒時分段加速；不依拍牌正確與否改變閃爍。
- 維持減少動態效果設定時的靜態紅框，避免重要警示消失。
- 以 5 種螢幕尺寸測試座位、按鈕與卡牌的矩形碰撞，均無互相重疊；遊戲引擎測試 19 項全數通過。

## V1.9.3｜四人環繞版 CSS 結構修正

- 修復 `style.css` 中未閉合的媒體查詢，避免將 V1.8～V1.9.2 的心臟病版面樣式誤限於「減少動態效果」設定。
- 恢復上、右、下、左四區定位，並將「拍」「翻」「累計受罰」分離於獨立框，恢復倒數最後三秒加速閃爍的紅框。
- 升級靜態資源版本至 V1.9.3，新增 CSS 括號與四向座位回歸測試。拍牌規則引擎未改動。
